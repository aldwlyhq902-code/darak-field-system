# مفتاح توقيع تطبيق دارك — اقرأ هذا قبل أي شيء

الملفان `darak-release.p12` و`key.properties` في هذا المجلد **غير مرفوعين على git عمداً**.

## احتفظ بنسخة منهما خارج هذا الجهاز اليوم

أندرويد يرفض تحديثاً موقّعاً بمفتاح مختلف عن المثبَّت. **ضياع هذا المفتاح يعني
أن أي نسخة مستقبلية لن تُثبَّت فوق النسخة الحالية** — الحل الوحيد حينها إلغاء
تثبيت التطبيق من كل جهاز وإعادة تثبيته من الصفر، وفقد أي بيانات محلية غير مزامنة.

انسخهما إلى مكانين منفصلين (مدير كلمات مرور + قرص خارجي مشفّر). لا ترسلهما في
واتساب ولا بريد.

## البصمة

```
SHA-256: B0:E1:01:7F:9F:F3:DC:0D:C4:7F:62:D7:A7:FA:53:C7:9B:0A:63:5F:42:07:D0:86:1D:D1:4B:30:DA:2F:D2:B0
صالح حتى: 2 أغسطس 2056
```

قارن هذه البصمة عند أي بناء لاحق للتأكد أنك توقّع بنفس المفتاح:

```bash
keytool -list -v -keystore darak-release.p12 -storepass <كلمة السر>
```

## البناء

```bash
cd mobile
flutter build apk --release --split-per-abi --dart-define=DARAK_API=https://panel.darak.sa
```

بدون `key.properties` يرجع البناء تلقائياً لمفتاح التصحيح — يعمل محلياً، لكنه
**لا يصلح للتوزيع**: مفتاح التصحيح مشترك بين كل مطوري أندرويد في العالم، فأي
شخص يستطيع بناء «تحديث» يُثبَّت فوق تطبيقك.
